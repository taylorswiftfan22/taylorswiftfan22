### What I work on

- **C++** — my main language. Native Windows tooling, from low-level memory and hooking code up to the UI on top.
- **Game internals** — in-process work inside game engines: function and vtable hooking, recovering engine classes
  and structures, rendering and overlay hooks.
- **Game externals** — out-of-process tools: reading and writing process memory, pattern scanning, pointer chains,
  overlays.
- **Source 2** — in-depth knowledge of the engine: the schema system, entities, interfaces, convars and console
  commands, user command protobufs, and keeping signatures and offsets alive across game updates.
- **Low-level reverse engineering** — x64 disassembly, reversing protected and authentication modules, working from
  game and memory dumps, rebuilding classes and data layouts from binaries.
- **Windows internals** — PE images and the loader, virtual memory, threads and synchronisation, API and inline
  hooks.
- **UI design** — a lot of UI work: custom menus, themes and layouts for native tools, designed and built from
  scratch.
